# Reunioes Do Projeto

Este diretorio guarda uma ata por reuniao. A ata preserva contexto, discussoes, decisoes, encaminhamentos e pontos ainda abertos sem transformar hipoteses em decisoes.

## Fluxo Padrao

1. Criar `AAAA-MM-DD-tema-curto.md` a partir de `TEMPLATE_ATA.md`.
2. Registrar separadamente: discutido, decidido, encaminhado e pendente.
3. Atualizar `docs/PROXIMOS_PASSOS.md` somente com tarefas ou decisoes abertas.
4. Registrar a sessao em `docs/DIARIO_DE_TRABALHO.md`.
5. Atualizar `docs/MEMORIA_ideiaMides.md` apenas quando a reuniao mudar o estado metodologico do projeto.

## Regras De Leitura

- MIDES observa pagamentos, nao adesao juridica.
- SICONFI nao identifica o CNPJ destinatario.
- Resumo automatico e material de apoio; a ata deve priorizar a transcricao e marcar incertezas.
- Informacoes pessoais ou administrativas sem efeito no projeto nao entram na ata versionada.
